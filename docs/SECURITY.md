# 安全说明

## 威胁模型

OFTerm 提供终端访问，天然具有高权限能力。我们假设：

- 飞牛 fnOS 网关负责 NAS 登录态校验。
- 应用自身仍必须做业务鉴权。
- 客户端输入、路径、主机名、终端输出均不可信。
- 本机其他用户可能尝试连接应用的 Unix Socket 或调试端口。

## 关键措施

- 访问控制由 fnOS 网关负责；应用只从 Unix Listener 读取 `X-Trim-*`，TCP Listener 上忽略这些 Header。直连模式默认仅绑定 `127.0.0.1`。
- 不设应用密码；直连模式使用当前系统用户，网关模式使用 `X-Trim-*` 身份。
- 所有变更请求校验 Origin 与自定义请求头，防 CSRF。
- WebSocket 使用一次性、短期、绑定用户/监听器/Origin 的 ticket。
- 不提供主机或凭据托管；本地 Shell 以当前 fnOS 用户身份运行。
- 不存储 SSH 主机或凭据；用户在 Shell 内自行使用 ssh，凭据由用户/fnOS 管理。
- API 与日志脱敏；会话 ticket 一次性、短期、绑定用户。
- 会话断开 grace 后终止进程组；无持久 PTY。
- 限额：会话数、连接数、请求体、粘贴大小。
- 安全响应头：CSP、`frame-ancestors`、`X-Content-Type-Options`、`Referrer-Policy`。

## 已知风险

- 应用以 root 运行（生命周期与系统访问需要）。我们通过强制认证、默认仅 Unix Socket、管理员限制和最小端点降低风险，但不能消除“终端即远程执行”的本质风险。
- 用户主动运行的命令、安装的软件、SSH 目标主机的安全性由用户负责。
