# Clean-room 说明

OFTerm 是对已存在应用 FntermX 的独立重写。FntermX 未公开源码，因此本项目采用 clean-room 方式：只根据公开可观察的行为整理功能清单，再独立设计实现。

## 调研范围

在公开分发的 `.fpk` 上进行了以下静态调研：

- 解包，确认包结构与生命周期脚本（`manifest`、`cmd/`、`config/`、`wizard/`、`app.tgz`）。
- 读取压缩后的前端产物，整理可见功能、设置项、配色名称与 API/WebSocket 行为。
- 反汇编 PyInstaller 后端，仅用于整理数据表字段、API 路由、认证方式与已知缺陷。
- 在飞牛论坛与公开文章中核对安装方式、用户反馈与已知问题。

## 未复用的内容

- 未复制或链接任何 FntermX 源代码、字节码、二进制、图标、预览图、文案或配置文件模板。
- 未复制任何 FntermX 数据库结构定义；OFTerm 使用独立的 bbolt 模型。
- 未复制 iTerm2 的源代码或资源文件。iTerm2 配色仅以“数值颜色数据 + 兼容性名称”的方式独立转录，见 `themes/PROVENANCE.md`。
- 未使用上游作者的商标作为项目名称；OFTerm 是独立名称。

## 实现独立性

- 后端：Go 标准库 + 宽松许可库；会话模型、WebSocket 协议、认证、存储、进程收敛均为新设计。
- 前端：React + TypeScript + xterm.js；布局、组件、设置 schema、主题数据管道均为新设计。
- 图标与截图：全部自制。

## 证据保留

行为调研的原始命令与结论保留在开发记录中，不随发布物分发。任何后续贡献者不得把逆向得到的代码片段提交到本仓库。
