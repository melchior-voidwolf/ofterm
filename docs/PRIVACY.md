# 隐私说明

OFTerm 是一个自托管应用，默认不收集、不传输任何用户数据。

## 收集的数据

- 应用配置、命令片段、审计日志：仅保存在本机应用数据目录。
- 终端输入输出：仅在浏览器与 NAS 之间通过本地/网关 WebSocket 传输，不写入磁盘。
- 日志：默认记录连接、退出、错误等运维信息，不记录终端内容。

## 外部请求

- 默认不访问任何第三方服务，无遥测、无崩溃上报、无广告。
- 用户在终端内主动运行 ssh 时，连接由系统 ssh 客户端发起。
- 没有默认的远程字体、CDN 或分析脚本。

## 数据删除

卸载时由用户选择保留或删除应用数据。删除后不可恢复。

## 联系方式

隐私相关问题请通过仓库的 Issue 或安全渠道联系维护者。
